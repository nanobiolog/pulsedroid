# PulseDroid 🫀

**PulseDroid** is a modern, high-precision Android application for non-invasive cardiovascular and hemodynamic monitoring using smartphone sensors, scientifically based on [ubicomplab/Seismo](https://github.com/ubicomplab/Seismo).

By placing your smartphone on your chest, PulseDroid uses the built-in accelerometer to capture **Seismocardiography (SCG)** micro-vibrations generated by heart valve motion and aortic ejection. When combined with **Photoplethysmography (PPG)** via the camera flash on your fingertip, PulseDroid calculates **Pulse Transit Time (PTT)** to estimate **Blood Pressure (BP)**, **Heart Rate (BPM)**, **Heart Rate Variability (HRV)**, and cardiac rhythms in real time.

---

## 🌟 Key Features

- **Dual Operating Modes**:
  1. **Chest-Only Mode (SCG)**: Place the phone flat on your chest over your sternum to measure resting Heart Rate (BPM), Heart Rate Variability (HRV / RMSSD), cardiac rhythm, and motion stability without touching the camera.
  2. **Dual Mode (SCG + PPG)**: Place phone on chest while resting your index finger gently on the rear camera flash. Measures Pulse Transit Time (PTT) and estimates Systolic & Diastolic Blood Pressure (mmHg).
- **Medical-Grade Real-Time Oscilloscope UI**:
  - Custom hardware-accelerated 60 FPS Canvas oscilloscope rendering anti-aliased SCG and PPG waveforms.
  - Real-time beat detection markers aligning aortic valve opening with capillary pulse arrival.
  - Animated pulsing heart rate gauge and stability status pill.
- **Hemodynamic Blood Pressure Estimation**:
  - Based on Moens-Korteweg and Bramwell-Hill physiological arterial stiffness models.
  - Includes user calibration dialog to align readings with standard reference cuff measurements.
- **Hands-Free Measurement Control**:
  - Press the physical **Volume-Down** button to start and stop recording hands-free while lying down or holding the phone steady.
  - Gentle haptic feedback on each detected heartbeat.
- **Scientific CSV Data Recording & Export**:
  - Full session logging compatible with research pipelines:
    - `seismo_accel_*.csv`: Timestamped 3-axis accelerometer data (~400 Hz).
    - `seismo_gyro_*.csv`: Timestamped 3-axis gyroscope data.
    - `seismo_ppg_*.csv`: Optical luminance channels (R, G, B).
    - `seismo_ptt_*.csv`: Instantaneous pulse transit times.
    - `seismo_summary_*.csv`: Complete metrics and session metadata.
- **Recorded Session History**:
  - Browse past recordings, view duration, average BPM, PTT, and BP category.
- **Automated CI/CD**:
  - Built-in GitHub Actions workflow compiling and publishing debug APKs on every push.

## 🔬 How It Works

Pulse Transit Time (PTT) is the time required for a pulse pressure wave to travel from the aortic valve in the heart to a peripheral capillary site (such as the fingertip). Because arterial elasticity and vascular tone vary with pressure:
$$\text{PTT} \propto \frac{1}{\sqrt{\text{Blood Pressure}}}$$

$$\text{Systolic BP} = \frac{a_s}{\text{PTT}} + b_s$$

1. **Aortic Valve Opening (SCG)**: The heart's mechanical contraction creates micro-vibrations transmitted through the chest wall. The phone's accelerometer records these vibrations at ~400 Hz. A 4th-order Butterworth bandpass filter (20 Hz - 50 Hz) and a non-linear quadratic energy filter isolate the aortic opening peak.
2. **Peripheral Arrival (PPG)**: The rear camera and LED flash illuminate the capillary bed of the fingertip. The pulsatile blood volume causes subtle luminance shifts sampled at 30–60 FPS.
3. **PTT Differential**: When a PPG peak occurs, PulseDroid scans backward into the SCG buffer (between $t-110$ and $t-240$ samples) to pinpoint the exact preceding aortic ejection. The delta represents the physiological Pulse Transit Time in milliseconds.

## 📱 Measurement Guide

1. **Rest**: Sit or lie down comfortably in a quiet area for 2 minutes before measuring.
2. **Chest Placement**: Place the back of the phone flat against your bare chest or light clothing directly over the **lower sternum** (center of the chest).
3. **Finger Position (Dual Mode)**: Rest your index finger gently over the rear camera lens and flash. Do not press hard, as excessive pressure can occlude capillary flow.
4. **Remain Still**: Watch the **Stability** pill at the top. When it reads `Stable`, tap **Start Sensing** or press **Volume Down** to begin recording.

## 🛠️ Building & Developing

### Prerequisites
- JDK 17
- Android SDK (API Level 35, Min SDK 26)

### Local Build
```bash
# Clone the repository
git clone https://github.com/nanobiolog/pulsedroid.git
cd pulsedroid

# Run unit tests
./gradlew test

# Build debug APK
./gradlew assembleDebug
```
The resulting APK will be generated at:
`app/build/outputs/apk/debug/app-debug.apk`

---

## 🚀 GitHub Actions CI/CD

PulseDroid includes `.github/workflows/build-apk.yml`. Every push or pull request automatically:
1. Validates DSP unit tests (`./gradlew test`).
2. Compiles the Android debug APK (`./gradlew assembleDebug`).
3. Uploads `PulseDroid-debug-apk` as an artifact available for download in the Actions tab.
4. If a tag like `v1.0.0` is pushed, automatically drafts a GitHub Release with the APK attached.
